# VnHance Studio Website Demo

A responsive React + Vite homepage concept for VnHance Studio.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
npm run preview
```

The production website is generated in the `dist` folder.

## Before showing/publishing to the client

- The original logo photograph is in `public/images/vnhance-logo-wall.png`.
- Replace the three demo project images with the studio's actual project photos/videos.
- Confirm the WhatsApp number and Instagram profile with the client.
- Confirm all service descriptions and brand copy with the client.
- The project imagery currently uses external Unsplash image URLs and requires an internet connection.

## Main files

- `src/main.jsx` — page sections, navigation and content.
- `src/styles.css` — design, responsive layout and CSS animations.
- `public/images/vnhance-logo-wall.png` — supplied VnHance logo photograph.
